# Gym Buddy Pro

crie um app para a realização de treinos de musculação em academia com os seguintes parâmetros:
-o aluno possa lançar os exercícios, onde ele possa inserir, o Nº de séries, gif, foto ou link do youtube do exercício e que faça a contagem de tempo de descanso entre um exercício e outro, avisando através de um poup-up no celular o final do exercicio e passando automatcamente para o próximo assim que ele marcar a conclusão do exercício;
-Lembrando que os treios são divididos em exercícios e que seja marcado o tempo total do treino;
-Que o aluno possa nomear os treinos também;
-Que o usuario possa criar treinos vários, com vários exercícios;
-Que o usuários possa salvar localmente por dia, com visão de calendário;
